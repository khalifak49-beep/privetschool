# نظام إدارة المدارس الخاصة — SchoolSys

منصة واحدة متكاملة تربط **الإدارة والمعلمين والطلاب وأولياء الأمور**، مبنية على
ASP.NET Core MVC 9 و Entity Framework Core و SQL Server، بواجهة عربية كاملة (RTL).

---

## 🚀 التشغيل السريع

```bash
cd SchoolSys
dotnet run
```

عند أول تشغيل يقوم النظام تلقائياً بـ:
1. تطبيق ترحيلات قاعدة البيانات (`SchoolSysDb` على `.\SQLEXPRESS`).
2. إنشاء الأدوار العشرة وصلاحياتها.
3. زرع بيانات تجريبية واقعية (1,250 طالب · 86 معلم · 42 شعبة).

> الزرع يحدث مرة واحدة فقط — إذا وُجد طلاب في القاعدة يتم تخطيه.
> لإعادة البناء من الصفر: `dotnet ef database drop -f && dotnet run`

### سلسلة الاتصال
في [SchoolSys/appsettings.json](SchoolSys/appsettings.json):
```
Server=.\SQLEXPRESS;Database=SchoolSysDb;Trusted_Connection=True;TrustServerCertificate=True
```

## 👥 الأدوار والصلاحيات

10 أدوار جاهزة، و**68 صلاحية** موزّعة على 14 مجموعة. الصلاحيات تُخزَّن كـ Role Claims
ويتم فحصها عبر سياسات ديناميكية:

```csharp
[HasPermission(Permissions.StudentsEdit)]
public async Task<IActionResult> Edit(int id) { ... }
```

وفي الواجهات:
```cshtml
@if (User.Can(Permissions.FinancePayments)) { ... }
```

القائمة الجانبية وأزرار الإجراءات تختفي تلقائياً لمن لا يملك الصلاحية، إضافةً إلى
الحماية على مستوى الـ Controller. دور `SuperAdmin` يتجاوز كل الفحوصات.

تُدار الصلاحيات بصرياً من: **إدارة النظام ← الأدوار والصلاحيات ← الصلاحيات**.

### التقنيات
| المجال | التقنية |
|---|---|
| الإطار | ASP.NET Core MVC 9 |
| قاعدة البيانات | SQL Server + EF Core 9 |
| الهوية | ASP.NET Identity (مفاتيح `int`) |
| الإشعارات الفورية | SignalR |

| تصدير Excel | ClosedXML |

كل المكتبات الأمامية **محلية** داخل `wwwroot/lib` — النظام يعمل دون إنترنت.

## 📱 التوافق مع الجوالات والأجهزة اللوحية

النظام مُختبَر فعلياً على 7 مقاسات (من iPhone SE حتى شاشة 1920px) وعلى 6 صفحات رئيسية —
**بلا أي تمرير أفقي** وبلا أهداف لمس صغيرة.

| الميزة | التفاصيل |
|---|---|
| الجداول على الجوال | تتحول تلقائياً إلى **بطاقات** يظهر فيها عنوان كل حقل بجانب قيمته — دون تعديل أي صفحة |
| شريط تنقل سفلي | يظهر على الجوال فقط، بروابط تتغيّر حسب صلاحيات المستخدم ودوره |
| الفلاتر | تُطوى تلقائياً على الجوال، وتُفتح وحدها إذا كان هناك فلتر مُفعّل مع عدّاده |
| القائمة الجانبية | تنزلق من الحافة، مع خلفية معتمة وزر إغلاق ودعم **السحب بالإصبع** |
| iOS | حقول بحجم 16px لمنع التكبير التلقائي، دعم `safe-area` لأجهزة النتوء، و`100dvh` بدل `100vh` |
| Android | `theme-color` لشريط الحالة، وأهداف لمس لا تقل عن 40px |
| التبويبات | تنزلق أفقياً بدل أن تتكدس |
| تقليل الحركة | يحترم `prefers-reduced-motion` فتتوقف كل الحركات |

الجدول الدراسي يبقى شبكة أفقية قابلة للتمرير (لأن تكديسه يفقده معناه) عبر الفئة `no-stack`.

الملفات المسؤولة: [responsive.css](SchoolSys/wwwroot/css/responsive.css) و
[responsive.js](SchoolSys/wwwroot/js/responsive.js).

## 🔔 تسجيل الحضور بـ QR

كل طالب يملك رمزاً فريداً (`QrToken`) يظهر في بطاقته. شاشة **تسجيل بـ QR** تدعم:
- الكاميرا مباشرة عبر `html5-qrcode`.
- أجهزة الماسح الضوئي (تعمل كلوحة مفاتيح) — ضع المؤشر في الحقل وامسح.
- المسح الأول = حضور (مع احتساب التأخير)، والثاني = انصراف.

## ⚙️ ملاحظات التشغيل الفعلي

قبل النشر في بيئة إنتاج:

1. **الرسائل الخارجية** — الصادر يُخزَّن في جدول `OutboxMessages`، ويحتاج ربط مزوّد
   فعلي (Twilio / WhatsApp Business API) داخل `CommunicationController.ProcessOutbox`،
   ويُفضّل نقله إلى `BackgroundService`.
2. **كلمات المرور الافتراضية** — غيّر كلمة مرور `admin@school.local` فوراً.
3. **البيانات التجريبية** — `DemoDataSeeder` يعمل فقط عند خلو جدول الطلاب؛ احذفه أو
   عطّل استدعاءه من `DbSeeder.SeedAsync` قبل الإنتاج.
4. **رفع الملفات** — تُحفظ في `wwwroot/uploads`؛ انقلها إلى تخزين خارجي عند التوسّع.
